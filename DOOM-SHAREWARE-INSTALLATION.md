# DOOM shareware — instalação privada
Resultado: INSTALADO — PRONTO PARA TESTE HUMANO. Executável DOS DOOM.EXE original e DOOM1.WAD do shareware v1.9, episódio 1, obtidos no mesmo pacote. Não é Freedoom nem o Doom comercial completo.

Fonte: https://www.gamers.org/games/doom/ indica o arquivo shareware DOS. Download pessoal: https://www.gamers.org/pub/idgames/idstuff/doom/doom19s.zip. Trata-se do arquivo idstuff da distribuição histórica; o README original identifica v1.9/shareware e seus dados permanecem separados do código aberto do motor. Não se atribui licença GPL ao WAD ou ao executável DOS original.

O ZIP é um instalador multipartes: INSTALL.BAT, DEICE.EXE, DOOMS_19.DAT, DOOMS_19.1 e .2. Os dois volumes de dados formam DOOMS_19.EXE, autoextrator ZIP, cujas 20 entradas foram extraídas sem executar o instalador no Windows. Dados e executável originais preservados. A instalação pessoal usa os arquivos extraídos, incluindo documentação e utilitários; o pacote original também foi mantido privadamente.

DOOM1.WAD possui 4.196.020 bytes; DOOM.EXE 709.905 bytes. Hashes completos no inventário. O perfil utiliza 20000 ciclos e configuração padrão do runtime, sem novo adapter, PWAD ou parâmetro remoto. A tela original de DOOM foi exibida no Chrome. Áudio, desempenho, controles e saves não foram homologados. Controles previstos: setas, Ctrl, Espaço, F2/F3 e Esc no jogo; Shift+Esc libera foco.

Os dados ficam somente na instalação pessoal fora do repositório/build. Não foi autorizada publicação ou redistribuição de um novo pacote de DOOM. Na instalação local ativa o Launcher armazena os bytes no IndexedDB e habilita Iniciar Jogo; em uma build restaurada sem os arquivos pessoais, continua disponível a importação guiada.
