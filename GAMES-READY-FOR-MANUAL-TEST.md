# Jogos preparados para avaliação humana
| Jogo | Status real da entrega | Como iniciar | Arquivos necessários |
|---|---|---|---|
| Prince of Persia DOS | Perfil preparado / aguardando arquivos | Launcher → Teste manual / perfis 003N → perfil → importar → Jogar | PRINCE.EXE, LEVELS.DAT e todos os DAT/arquivos da edição DOS |
| DOOM shareware | Perfil preparado / aguardando arquivos | Mesmo painel, perfil DOOM | DOOM.EXE DOS + DOOM1.WAD e dados da mesma edição |
| Duke Nukem 3D shareware | Perfil preparado / aguardando arquivos; desempenho em avaliação | Mesmo painel, perfil Duke | DUKE3D.EXE DOS + DUKE3D.GRP e demais dados/configuração |
| Freedoom / Ken / SkyRoads | Pacotes autorizados preservados da 003M | Launcher, selecionar título e Iniciar Jogo; também atalhos Abrir no painel | Já fornecidos na base |

Nenhum candidato novo foi declarado instalado na entrega sem dados. Os três perfis permitem tentativa real depois de importar, não são fichas com botão falso. Instalado significa arquivo presente/reconhecido; não significa execução verificada. Não houve boot de candidato comercial nesta missão por ausência de dados autorizados. A inicialização curta foi feita somente com Disquete Perdido DOS original.

Homologação é responsabilidade do proprietário. O painel permite Ainda não testado / Funcionou / Não funcionou / Apresentou problemas e observações locais. A confirmação explícita de homologação só se habilita com Funcionou; não é preenchida automaticamente. Os testes técnicos usaram perfis temporários separados do navegador do proprietário.
