# Prince of Persia — instalação privada
Resultado: INSTALADO — PRONTO PARA TESTE HUMANO, edição demo DOS 1.0. Não é o jogo completo. A fase limitada da demonstração foi exibida no Chrome; não foram testados todos os controles nem save.

Origem: https://www.dosgamesarchive.com/download/prince-of-persia e https://image.dosgamesarchive.com/games/pop1demo.zip. O pop1.txt que acompanha o pacote identifica demonstração interativa comercial e aponta a origem histórica http://www.broderbund.com/demo/ (captura de 01/02/1998). O endereço histórico não foi usado como prova de que um download completo atual está autorizado. A única edição obtida foi a demo, para utilização pessoal; não foi incluída em Git, bundle ou build.

A camada externa contém pop1.zip e scripts de conveniência do arquivo; não foram executados. O autoextrator DOS pop1demo.exe contém ZIP legível e foi extraído como dados. Conteúdo real da demo: CDUNGEON.DAT, DIGISND1/2/3.DAT, EDUNGEON.DAT, GUARD.DAT, GUARD2.DAT, IBM_SND1/2.DAT, KID.DAT, LEVELS.DAT, MIDISND1/2.DAT, PRINCE.DAT, PV.DAT, TITLE.DAT, VDUNGEON.DAT e PRINCE.EXE. Nenhum executável foi alterado.

Perfil usa PRINCE.EXE, 6000 ciclos fixos e runtime DOSBox existente. O validador agora exige LEVELS, PRINCE, KID, GUARD, VDUNGEON e TITLE; exigir só LEVELS era insuficiente. Lista completa e hashes no inventário de evidência. Dados reais presentes não são substituídos por fixtures.

Abrir o servidor pessoal → Launcher → coleção Prince / DOOM / Duke → Prince of Persia — demo DOS 1.0 → Iniciar Jogo → Iniciar jogo DOS → Focar no jogo. Setas/Shift e demais teclas conforme a edição; Shift+Esc libera foco. A demo informa Ctrl+Q para sair. Não se promete salvamento na edição limitada. Para o jogo completo, importar os arquivos de uma cópia legitimamente obtida; os dados completos não foram adquiridos nesta missão.
